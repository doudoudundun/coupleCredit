# 物资页：外凸与内凹双滚轴

本轮修正下方摘要为「物品名称＋数量」，恢复绿色竖条，并将原来平直的下方窄卡改为内凹滚轴。前一版记录见 `INVENTORY_CONVEX_ROLLER_20260915.md`；其中「类目摘要、远卡倾角为零」已被本轮替代。

## 衔接方式

- 中上部焦点保持原尺寸及位置，上邻卡 +12°、下邻卡 −12°，保留外凸方向。
- 距焦点下方 1–3.4 行，倾角沿同一条 smoothstep 曲线从 −12° 连续变为 +12°；2.2 行处经过内凹滚轴的平直中心。两端角速度为零，接入前一段时没有倾角或速度跳变。反拖使用同一曲线。
- 内凹中心仅收窄 1.5%，辅助表达向屏幕内退让的深度。高度不做比例压扁，窄卡仍为真实 32dp 卡体；名称、数量和绿色竖条随完整卡面一起透视。
- 保留原来的卡体高度、间距、内容透明度连续插值，以及原生惯性、吸附和边缘渐隐。没有添加按行触发的过渡动画、整卡闪灭或裁剪交接。
- 窄卡名称替换原类目绑定及控件命名；左侧恢复 3×16dp 绿色标记，与完整卡摘要使用相同的起始边距。名称单行省略，数量靠左避开右下悬浮按钮。
