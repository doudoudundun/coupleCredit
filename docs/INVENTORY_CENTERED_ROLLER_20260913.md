# 物资页：单列中央滚轴

在已验收的双列叠层基础上，按用户的新设计调整为单列中央焦点。

- 每行一张物资卡；中央卡清晰、完整并处于最前层。
- 上、下卡片都叠在中央卡后方，按距离对称缩小、倾斜与轻微虚化。
- 滑动后吸附到中央；点击任一上下后层卡片先将其展开，只有中央稳定卡片允许业务操作。
- 列表两端不重复数据，首项/末项均能停在中央，空侧自然留白。
- 移除底部提示栏及其预留空间；刷新、添加独立悬浮在右下方。
- 最近动态、辅助阅读模式同步使用单列普通列表。

## 当前版本：稳定层叠，仅顶部退出渐隐（2026-09-13 22:22）

用户先否定裁剪交接造成的切片感，随后在真机反馈“整卡淡出再恢复”快速滑动时反复闪烁。两种实验交接均已移除，当前以初版的稳定实体卡片层叠为基准：

- 卡片保持整体，不执行交接裁剪，也不按每行相位反复淡出和恢复。
- 中央及相邻行不透明，透明度仅用于顶部退出和最远层离场。顶部渐隐按位置连续计算，中央卡片即使在短 viewport 中也保持 alpha=1。
- 保留线性位移、小数像素和已有尺寸复用，避免恢复初版临时扩距导致的反向运动。
- 遮挡顺序恢复按距中央的深度排序；不声称这已实现完全无感的 Z 顺序交接，优先恢复稳定快速滑动。
- 所有非稳定前卡区域（包括无可见卡片的区域）由 RecyclerView 处理手势，避免透明卡片的隐藏按钮收到业务点击。

## 拖动跟手修正（2026-09-13 晚间，历史版本）

用户真机反馈层级交换附近抖动。根因是初版正弦平方扩距：64dp 静止间距、192dp 卡外高时，部分卡片的位移导数会改变符号，手指单向移动却出现反向位移；交换 Z 也会令整个重叠区域突然换卡。

当前版本取消扩距，采用固定线性位移 `top = anchor + distance × pitch`。上、下两张交接卡使用同一屏幕水平边界逐步移交重叠区域，再逆矩阵映射为各自 `clipBounds`。裁剪施加到卡片本身，避免硬件 Z 重排绕过 `drawChild` 外的 Canvas 裁剪。点击命中使用相同交接边界；其他卡片、整数吸附位及移除布局时清除裁剪。

同时保留小数像素 `translationY`，减少慢拖取整跳动；拖动时复用已测量尺寸，新附着卡及正式布局仍测量。松手吸附逻辑保留，静止的单列中央滚轴外观不变。运动中相邻卡片在共同边界被逐步遮挡，属于当前方案的视觉取舍。

- 构建通过，80 项 JVM 测试通过，包括多行单调位移、反向重走和半行交接连续性。
- PKB110 真机：6 秒慢速正向拖动分阶段截帧、5 秒反向拖动截帧、上下后层点击、松手恢复完整卡片、最近动态切换返回均完成。
- 本机三次连续滑动短程采样：191 帧，Janky 9（4.71%）；P50 16ms、P90 21ms、P95 24ms、P99 27ms。仍存在少量系统标记卡顿，不能声称所有帧均流畅；此次主要修复轨迹反向及整块遮挡跳变。
- 最终 APK 已安装且设备与本地 SHA-256 一致：`3d3ca44b7b61e3f032b6192d42d0c49930d8649da5860893cce333f3d2c8b012`。

### 动效参数

- 卡体 184dp，外部含 margin 后 192dp；固定图片/状态/摘要布局，避免可选备注改变行高。
- 静止相邻卡片间距 64dp，一行滑动相位对应 120dp 手势距离；最多附着 9 行。
- 中央锚点扣除列表上下 padding 后计算；上下按绝对距离对称缩放、模糊和后移，旋转方向相反。
- 最远缩放 0.86，最大 X 轴倾角 8°；0–2.5 行内不透明，2.5–4 行渐隐到 0。
